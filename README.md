# Student Management Mini App (Angular + TypeScript)

A small Angular standalone project built to practice TypeScript fundamentals
and understand how Angular components work without NgModules.

##  Features
- Angular Standalone Components
- TypeScript-based logic
- Display a list of students
- Pass / Fail status based on grade
- Clean and simple project structure

##  Technologies Used
- Angular (Standalone Components)
- TypeScript
- HTML
- CSS
- Node.js

## 📁 Project Structure

```
src/
├── main.ts
└── app/
    ├── app.ts
    ├── app.html
    └── students/
        ├── students.ts
        ├── students.html
        └── students.css
```

##  How to Run the Project

1. Clone the repository:
   ```bash
   git clone <repository-url>
2. Install dependencies:
```bash
npm install
```
3. Run the development server:
```bash
ng serve
```
4. Open your browser and visit:
```arduino
http://localhost:4200
```
